# Catalyst Lab

Catalyst Lab is an AI-powered virtual chemistry laboratory designed to make chemistry learning safer and more interactive.

## Key Features
- Virtual chemical reaction simulations.
- AI-powered safety monitoring and guidance.
- Interactive experiment environment.
- Chemical search and drag-and-drop functionality.
- AI-generated scientific explanations.
- Student progress tracking and performance reports.

## User Roles
- **Student:** Perform experiments and view results.
- **Teacher:** Manage experiments and monitor student progress.
- **Admin:** Manage users and system resources.

## Project Management
Developed using the Agile/Scrum methodology as part of a Software Engineering project at Arab American University (AAUP).
